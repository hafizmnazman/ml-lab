# Course datasets

These 12 files were extracted unchanged from the supplied `all_datasets.zip`.
The small course dataset bundle is included in this private study repository,
so a clone can run both notebooks immediately after environment setup.
The handwritten-digits ZIP remains intact for later labs.

`manifest.json` records each file's size and SHA-256 hash. Some course files
can be subsets of upstream datasets; use these exact copies when comparing
results. Original datasets retain their respective terms. Course handouts
and the original bundle are stored locally in `course_materials/`.

Labs 1-2 use Titanic, breast cancer, student performance, medical costs,
daily/hourly bike sharing, and heart disease. Data preparation is performed
in the notebooks, leaving these source files untouched.
